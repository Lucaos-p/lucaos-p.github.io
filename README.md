# Lucas Pinheiro — Front-end Web Development

This repository contains Lucas Pinheiro's front-end coursework, portfolio demos, and supporting assets.

## Repository map

- `index.html` — public homepage
- `exercises/` — CA1 exercises and classroom projects
- `project-hero/` — hero-section design variations
- `portfolio/` — standalone Crypto Wallet and Smoothies demos
- `apps/hero/` — hero-generation examples, prompts, and outputs
- `assets/` — shared homepage images and favicons

The site is published with GitHub Pages from the `main` branch.
